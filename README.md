# 🐍 Snake Game - Sonserina

Jogo da Cobra desenvolvido em JavaScript puro com tema da Casa Sonserina de Harry Potter.

## 📋 Sobre o Projeto

Jogo da Cobra clássico desenvolvido com HTML, CSS e JavaScript puro, com visual temático da Sonserina — tons de verde escuro e prata.

## 🚀 Tecnologias Utilizadas

- **HTML5** (Canvas API)
- **CSS3** (animações e efeitos visuais)
- **JavaScript** (lógica do jogo)

## 🎮 Funcionalidades

- ✅ Movimentação da cobra com setas do teclado
- ✅ Sistema de pontuação
- ✅ Recorde salvo na sessão
- ✅ Detecção de colisão com bordas e corpo
- ✅ Tela de Game Over com mensagem específica
- ✅ Botão de reiniciar
- ✅ Visual temático Sonserina

## ▶️ Como Jogar

1. Abra o arquivo `snake.html` no navegador
2. Use as setas do teclado para controlar a cobra
3. Coma a comida prata para pontuar
4. Evite as bordas e o próprio corpo!
